1. **文字サイズの段数過多 1件が残っています**（釦 3段→2・値は 18/15/14px）。
   14px は手札の釦（へぎそばカード・錦鯉カード…＝JSが style 属性で 13px を直書き）で、15px にすると「へぎそばカード」（7字）が幅390で1列に入らず「…」に省かれます。札は釦と役割が違う（手元の札）ので 14px の段に置き、幅360などの端末では「…」で省いて横はみ出しを作らない設計にしました。素点3点ぶん（散らかり度3）が残りますが合格圏です。**点数の都合を役割の判断より先にしない**掟に従っています。

2. **`⚠地色` の印がついた色を1組寄せています**（`#fffdf7` → `#ffffff`・パネル／イントロ箱／🎯リング／音の釦の地）。
   `#fffdf7` と `--paper #f6f1e6` は**セクションの拍ではない**ことを先に確かめました。`--paper` は body の地（canvas に完全に覆われて見えない）と HUD の霞のグラデにだけ使われ、`#fffdf7` は浮く面の地でした。浮く面は物件カード・ghost 釦が既に `#fff` だったので、面の白を `#fff` の1本に揃え、生成りは HUD の霞と目的地の札（新設）に残しています。生成りの役割は消していません。

3. **定番度 20 は下げていません**（型紙 `emoji-icons` 2点＝🐑 万両・🎯・🔈・☀・🎲 の6箇所）。
   絵文字はこのゲームの言葉づかい（桃鉄風の軽さ）そのもので、外すかどうかは構成の選択です。SKILL.md の方針どおり機械は自動で外さず、「合格ライン到達・**型が残る**（絵文字）」と正直に書きます。1280 の `dual-cta`（買う／やめる）は CSS の格下げで消えました。直し方は証書の詳細ページに載せてあります。

4. **修理前のイントロ状態でメッセージが「☀ 朝市ボーナス +50万両」になっている**のは写しの都合です（状態固定スクリプトが保存を消すので、サイコロ満タン＝初日の朝市ボーナスが出る）。前後同一なので前後差には影響しません。

5. **`そろい`（整列ズレ・擬似要素・二重線・約物）と `なかみ`・`かさね`・βの`とおみ` は未実施です。** 本家の `scripts/soroi.js` などが同梱されておらず、再実装もしていません。ずれ度は参考点で最優先3件の外なので、判定には影響しません。

6. **余白の種類**（8/12/16/20/24 の5種）は SKILL.md どおり**報告のみ（採点外）**。全部4の倍数なので触っていません。

7. **サイコロ0個のときの無効釦（`#cfc6b3` に白文字）**は今回の5状態に出ないため台帳に載らず、見立て問い7の処方に留めました（修理デモに入れていない）。

### 正直な限界

- 破れの床は簡易検査で、WCAG適合判定ではありません。
- 地図（canvas）の描画は測っていません。地図の上の文字（地名ラベル・「カード売り場」など）は canvas が描いているので、金継ぎの対象外です。
- 実機（iPhone/Android）での目視はしていません。ダークモード・拡大表示・視差配慮での見え方は対象外です。`:has()` は iOS 15.4+／Chrome 105+ で動きます（それ以前はカードが元の位置に戻るだけで壊れません）。
- `assets/dice/*.mp4`（サイコロ動画）の再生品質は診断していません。検査に使う Chromium は HEVC 等のコーデックを積んでいないため、ここでの観測で「再生されない」と断定はできません（動線検収では動画の終了を待たず `busy` の解除で判定しました）。
- 素点の配点の一部はこちらで定めた値です（冒頭の但し書き）。
