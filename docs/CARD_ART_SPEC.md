# ながおか探検録｜お宝カード制作仕様書（ChatGPT画像生成用）

作成 2026-07-15。**実際の写真を参照して、今より一段リアルで美しいカードに作り替える**ためのガイド。

> **採用方針（2026-07-15 更新）**：masaの判断で、**枠・ロゴ・シルエットまで含めた"フルカード"を ChatGPT で一括生成**する（ChatGPTの方が飾りの描き込みがリッチ／地名はローマ字なので綴り崩れリスクが低い）。フルカード用プロンプトは §2.5 を参照。
> 下記の「アートだけ作って枠は後付け」方式は**保険**（枠がバラつく/綴りが崩れた時に Claude のテンプレ `tools/card_frame/build_card.js` で同じ枠を正確に上書きできる）。
> 統一感のコツ：2枚目以降は**気に入った既存カードを参照添付**して「この枠デザインに完全に合わせて」と指示する。豪華版は通常版を参照添付して"夜＋花火"化。

---

## 0. いちばん大事な3原則（これだけは絶対）

1. **画像に文字を入れさせない。** スポット名・ロゴ・看板の読める字はChatGPTに描かせない。
   → ChatGPTは漢字をよく崩す（「愛」が「支」になる等）。**文字と枠は後工程で正確に付ける**。
2. **比率は必ず縦2:3。** 最終は 768×1152px。生成は 1024×1536px でOK（あとで縮小）。
3. **画風は毎回同じ指定文をコピペして固定。** バラつくと図鑑全体が安っぽく見える。下の【画風】ブロックを毎回使い回す。

---

## 1. ねらいと進め方

- **写真参照でリアル寄りに。** 実際のスポット写真を1〜2枚添付し、その構図・特徴を活かして"絵画化"する。
- **1枚ずつ丁寧に。** 一括生成より、1スポットずつ納得いくまで作る。
- **通常版 → 豪華版の順で作る。** 豪華版は「通常版の画像を参照に添付」して夜＋花火にすると、構図と画風がピタッと揃う（重要テク）。
- できた「文字なしアート」を Claude に送る → 既存カードと同じ枠を付けて 768×1152 に整え、アプリに反映（キャッシュ更新・デプロイ）まで自動でやる。

---

## 2. プロンプト・テンプレート【通常版（昼）】

> 使い方：【　】を埋めて、実際の写真を添付して送る。【画風】ブロックは毎回そのままコピペ。

```
新潟県長岡市の「【スポット名】」を描いてください。参照写真を添付します。

【画風】温かみのある和の風景画。実際の写真の構図と色を活かしつつ、少し絵画的に整える（写実7：イラスト3）。やわらかな陰影、上質な和紙のような細かい粒状感、彩度は落ち着いたセピア寄り。自然光の昼、澄んだ空。日本画とレトロな観光ポスターの中間のような、品のある雰囲気。

【構図】縦長（アスペクト比 2:3）。主役の【建物／風景の特徴】を画面の中央〜やや上に大きく配置し、手前に【前景：参道・水面・石段・草花など】を置いて奥行きを出す。

【禁止】画像内に文字・ロゴ・読める看板は入れない（後で加えます）。実在の人物は描かない（必要なら小さな後ろ姿のシルエット程度）。

この場所の特徴を活かして、上記の画風で1枚描いてください。
```

---

## 2.5 プロンプト・テンプレート【フルカード（枠込み・採用ルート）】

> ChatGPTで枠・ロゴ・シルエットまで一括生成する場合。スポット写真を添付して使う。

```
新潟県長岡市の観光ポスター風「お宝カード」を1枚デザインしてください。参照写真を添付します。

【全体】ヴィンテージな旅行ポスター／レトロなご当地トレーディングカード風。縦長(2:3)。生成り(クリーム)の厚紙のような台紙に、中央の絵と装飾枠が一体になった上品なデザイン。

【中央の絵】「【スポット名】」を温かみのある和の風景画で(写実7:イラスト3、やわらかな水彩、落ち着いた彩度、自然光の昼)。参照写真の構図・特徴を活かす。人物は描かない。

【装飾枠】
・外周に、深い緑(ティール寄り)のインクで二重の罫線フレーム
・左側の余白に、地名を縦書きのローマ字ロゴで大きく：【AORE NAGAOKA】(太字レトロなサンセリフ、緑インク)
・四隅に花火モチーフの線画飾り(緑インク)
・下部に長岡ランドマークのシルエット帯(緑インク単色)：アーチ橋(大手大橋)、水道タンク、街並み、街路樹
・装飾はすべて緑インクの単色で統一

【文字ルール】ロゴの地名以外に読める文字を入れない。地名の綴りは必ず【AORE NAGAOKA】に正確に合わせる。

旅行ポスターのように、飾りまで作り込んで美しく仕上げてください。
```

豪華版：上で作ったカードを参照添付し「枠・ロゴ・シルエットはそのまま、中央の絵だけ夜＋花火に」と指示。

---

## 3. プロンプト・テンプレート【豪華版（夜＋花火）】

> 使い方：**先に作った通常版の画像を参照として添付**してから送る。これで構図と画風が揃う。

```
先ほど作った「【スポット名】」の通常版画像を、参照として添付します。
この画像と“まったく同じ構図・同じ画風”のまま、時間帯だけ夜に変えてください。

・夜空に大輪の花火を数発（長岡花火のイメージ。暖色の金・オレンジを主役に、赤や青を差し色に）
・建物の窓・灯り、参道の灯籠、提灯などに温かい明かりを灯す
・全体は静かな青い夜のトーン。でも花火と灯りで暖かく見えるように

【禁止】構図・建物の形・アスペクト比(2:3)は変えない。文字は入れない。人物は増やさない。
```

---

## 4. 参照写真のコツ

- できれば**昼・晴れ・正面〜斜め45度**の、そのスポットが主役の写真を選ぶ。
- 人物や車がたくさん写った写真は避ける（省いてと指示しても残りやすい）。
- 「構図はこの写真を踏襲、ただし画風は上記の指定で」と明言すると、写真の“ただの模写”になりにくい。

---

## 5. できあがりチェック（送る前に確認）

- [ ] 縦2:3になっている
- [ ] 画像内に文字が入っていない
- [ ] 画風が他のカードと揃っている（彩度・粒状感・トーン）
- [ ] 主役がちゃんと主役（中央〜やや上・大きめ）
- [ ] 豪華版は通常版と同じ構図のまま夜＋花火になっている

## 6. 運営（Claude）側でやる仕上げ

送ってもらった「文字なしアート」に対して、こちらで：
1. 既存カードと同じ**セピアの縁＋角飾りの枠**を付ける
2. **768×1152px** に整える
3. 正しいファイル名（`card_〇〇.png` / `card_〇〇_deluxe.png`）にリネーム
4. アプリに差し込み → キャッシュ番号を上げてデプロイ → 実機に反映

**だから masa は「良いアートを作ること」だけに集中すればOK。**

## 7. スポット名リスト（順次差し替え用）

全42スポット × 通常＋豪華。まずは露出の多い“顔”から差し替えると効果的：
アオーレ長岡 / 宝徳山稲荷大社 / 機那サフラン酒本舗 / 山古志 錦鯉の里 / 悠久山公園 / 山本五十六記念館 / 中山隧道 …
（ファイルIDとの対応表が必要なら Claude が渡します）
