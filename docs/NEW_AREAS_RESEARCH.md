## 1. 三島（みしま）エリア
2005年に長岡市へ編入。脇野町を中心とした里町。**「竹あかり」と「縄文の清水」「鋸鍛冶」がフック。**

**図鑑スポット候補**
- **蓮花寺の大杉** … 御神木の巨木（※蔵王の大けやきと同じ"巨木・御神木"枠で映える）。
- **越後みしま竹あかり街道** … 秋、約2万個の竹灯籠で通りをライトアップ。→ **イベント限定カード向き**（柿川灯籠流し方式）。
- **三島の散歩道（本町〜宮下町）** … 「縄文雪つらら」と名付けられた清水が湧き、酒蔵・そうめん屋・神社仏閣が並ぶレトロな街道。
- **脇野町の鋸（のこぎり）鍛冶** … 1842年、中屋庄兵衛が会津から帰郷し鋸製造の元祖に。伝統産業枠。
- 寺社：西照寺／寛益寺／根立寺、三島郷土資料館。

**隠しスポット候補** … 「縄文雪つらら」の湧水スポット、竹あかりの夜景ビューポイント。
**ゲーム連携** … おみやげ「竹あかり燈籠」「鋸キーホルダー」／イベント限定カード「竹あかり街道（秋）」。

## 2. 長岡川西（かわにし）エリア
信濃川の西岸一帯。※既存の**蔵王エリア（金峯神社・水道公園・大けやき・蔵王堂城跡）も川西**なので、被らないよう**「縄文・火焔土器＋花の丘陵公園」テーマ**で差別化するのがおすすめ。

**図鑑スポット候補**
- **馬高縄文館（火焔土器ミュージアム）** … 関原。**火焔土器"発見の地"**（馬高遺跡）。国宝級の火焔型土器。入口に触れる大型レプリカ。→ 縄文ブームで映え＆学び◎。
- **新潟県立歴史博物館** … 関原。火焔土器約90点＋「雪と暮らし」「縄文人の世界」の実物大ジオラマ。
- **国営越後丘陵公園** … 宮本東方町。バラ園・チューリップ・花畑・雪のそり遊び。四季の"映え"スポット。
- （関連）千秋が原ふるさとの森 など。

**隠しスポット候補** … 丘陵公園の花畑/紅葉ビューポイント、馬高遺跡の原っぱ。
**ゲーム連携（強力）**
- **着せ替え「縄文人（火焔土器スタイル）」** … 長岡＝火焔土器のまち。めちゃ映える衣装枠。
- おみやげ「火焔土器ミニチュア」「バラ」。日本遺産「火焔型土器」ストーリーと連動。

## 3. 出雲崎（いずもざき）エリア
日本海沿い、寺泊の北。**歴史の宝庫：良寛生誕地・妻入り街並み・天領・石油発祥・芭蕉・夕陽。**（※海エリアとして寺泊と連携）

**図鑑スポット候補**
- **良寛堂／良寛記念館** … 江戸期の名僧**良寛**の生誕地。長岡（越後）の偉人枠の大本命。
- **妻入りの街並み** … 海岸沿い約4km続く、全国的に珍しい町並み。
- **石油記念館（日本の石油産業発祥地）** … 近代産業遺産。
- **道の駅 越後出雲崎 天領の里／夕凪の橋** … 江戸天領。日本海の夕陽の名所（佐渡遥拝）。
- **松尾芭蕉 句碑** … 「奥の細道」で来訪・詠嘆の地。

**隠しスポット候補（絶景）** … **日本海に沈む夕陽ビューポイント**（佐渡遥拝）。時間帯限定演出と相性◎。
**ゲーム連携（強力）**
- **着せ替え「良寛さん（僧衣・托鉢）」**、さらに「松尾芭蕉（旅装束）」も候補。偉人着せ替えの弾に最適。
- おみやげ「良寛の手まり」「石油ランプ」「天領の塩」。

## 4. 中之島（なかのしま）エリア
2005年編入。刈谷田川沿いの米どころ。**「大凧合戦」が唯一無二のフック。**

**図鑑スポット候補**
- **見附今町・長岡中之島 大凧合戦** … 360年以上の伝統。六角凧「百枚張」（縦4.3m×横3.3m、畳約8枚分）が刈谷田川をはさんで空中で絡み合う勇壮な行事。毎年6月・新潟県無形民俗文化財。→ **イベント限定カード＆メインの見せ場**。
- 中之島の田園風景（米どころ）、中之島文化センター 等。

**隠しスポット候補** … 刈谷田川堤防の"大凧が舞う空"ビューポイント（夕景）。
**ゲーム連携** … **イベント限定カード「大凧合戦（6月）」**（柿川灯籠流し・竹あかりと同じ日付限定方式）／着せ替え「凧揚げ法被」／おみやげ「六角大凧ミニチュア」。

## 5. 越後川口（えちごかわぐち）エリア
2010年編入。**信濃川と魚野川の合流点**の河岸段丘。**「二大河川の合流絶景＋温泉＋中越地震震央」がフック（山古志と震災でつながる）。**

**図鑑スポット候補**
- **信濃川・魚野川 合流点** … 越後長岡百景「信濃川の渡し（川口）」。二本の大河が出会う絶景。
- **えちご川口温泉** … 合流点を望む露天（越後三山も一望）。ナトリウム塩化物泉。
- **川口きずな館／震央メモリアルパーク** … **2004年 中越地震の震央**（川口町・日本初の震度7・深さ13km）。→ **山古志エリア（震災復興）と歴史的に連携**。
- 日本遺産「火焔型土器」ゆかり地。

**隠しスポット候補（絶景）** … 合流点を見下ろす展望・**雲海/夕景ビューポイント**（山古志の金倉山ビューポイント巡りと同系統で強い）。
**ゲーム連携** … おみやげ「温泉まんじゅう」「合流点の景色」／震災メモリアルは山古志と物語連動。

## 6. 小国（おぐに）エリア
2005年編入。渋海川が貫く水と緑の山里。**「小国和紙（300年）＋城跡の絶景＋八石山」がフック（山古志系の山里映え）。**

**図鑑スポット候補**
- **小国和紙（生産組合・紙すき）** … 300年以上の伝統。国・県の無形文化財。**雪ざらし**製法。型染めの絵はがき。→ 伝統工芸枠＆おみやげに直結。
- **小国沢城跡（小城山）** … 山頂から小国平野を一望。**城跡枠**（蔵王堂城跡・与板城跡と同系統）。※源頼行が1133年に「小国保」を領地＝武将ゆかり。
- **小国民俗資料館**、**八石山**（八石なす）。

**隠しスポット候補（絶景）** … 八石山山頂／小国沢城跡からの雲海・棚田ビュー（山古志のビューポイント巡り方式）。
**ゲーム連携** … 着せ替え「紙すき職人」／おみやげ「小国和紙の絵はがき」「八石なす」／武将枠「源頼行」。

## 全体まとめ・提案の方向性

**A. 偉人・着せ替えの弾が増える**：良寛（出雲崎）、松尾芭蕉（出雲崎）、縄文人（川西・火焔土器）、源頼行（小国）、紙すき職人（小国）、凧揚げ法被（中之島）。牧野・山本五十六・直江兼続 に続く"なりきり"枠を大きく拡充できる。

**B. イベント限定カードの弾**：竹あかり街道（三島・秋）、大凧合戦（中之島・6月）。＝柿川灯籠流し方式（日付・時間限定出現→図鑑に永久保存）が横展開できる。

**C. 絶景・隠しスポット（雲海/夕陽/合流点）**：出雲崎の夕陽、越後川口の合流点雲海、小国の城跡・八石山。＝山古志ビューポイント巡り（錦鯉の根付で1つずつ解禁）と同じ"牧野解禁×絶景連番"の仕組みが効く。

**D. 学び・テーマの深化**：火焔土器（川西＝縄文）、良寛・天領・石油（出雲崎）、中越地震震央（越後川口↔山古志）、小国和紙。「遊びながら長岡を学ぶ」路線を強化。

**E. 実装の型は既存流用でOK**：エリア追加＝pois.json＋水彩エリア地図＋統一フレームのday/deluxeカード＋（任意で）着せ替え/おみやげ/牧野解禁/イベント限定。多言語(i18n)は pois_i18n.json に各スポットを追記すれば海外にも対応。

**次アクション（masa判断待ち）**：①どのエリアから着手するか ②各エリアの採用スポット確定（3〜5個/エリア）③着せ替え・限定カードの優先順位。決まればFable設計→フレーム制作→実装の順で進められる。
